>
> Ряд антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и помещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, лучше добавить исключение; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщик по умолчанию"
    * В Firefox включите "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * На роутерах Keenetic активируйте опцию "Транзит запросов". Если её отключить, настройка и работа Secure DNS на компьютере могут быть нарушены

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите нужный сценарий
    * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки автозапуска перейдите в **`service.bat`**: `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — проверка состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения этого режима стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках (включено/выключено).
  - **`IPSet Filter`** — настройка обхода сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает  
  В скобках показывается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — проверяется наличие IP в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если он не появился, обратитесь к [#522](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не подключается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное в конец `hosts` (или замените ранее добавленные аналогичные строки)
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранён.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/PennantBladeChaos/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Обнаружение меняется: стратегия, которая работала раньше, позднее может перестать работать.
> В проекте есть много вариантов обхода. Если ни один не подходит, создайте новую стратегию на основе представленной здесь, изменив её параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что адрес ресурса присутствует в списках доменов или IP

- Проверьте остальные стратегии (**`ALT`**, **`FAKE`** и другие)

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Выполните `service.bat` -> `Remove Services`
- Затем откройте `service.bat` -> `Run Diagnostics`; устраните ошибки и в конце выберите Y
- Удалите текущую папку с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву, откройте свойства и при наличии флажка разблокировки внизу справа установите его, затем нажмите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- По очереди запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если очередная стратегия не работает, закройте программу (значок замка находится на панели задач) и попробуйте следующую
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала помогать, проверьте все остальные.
- Дополнительная информация — в [#251](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Желательно определить стратегию, на которой открывается YouTube, и запустить её
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей
- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/PennantBladeChaos/tg-ws-proxy)
- Либо используйте бесплатные MTProto-прокси, доступные в интернете

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

- Опишите её [в разделе issues](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить (например, если IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не следует)
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
